# กติกาหลัก — I Know… You Don’t

เอกสารนี้เป็นแหล่งอ้างอิงหลักของกติกาเกม ใช้ประกอบการพัฒนา Offline Game Engine และ UI หากกติกาในโค้ดหรือเอกสารอื่นขัดกับไฟล์นี้ ให้ยึดกติกาที่ผู้เล่นยืนยันล่าสุด และแก้เอกสาร/โค้ดให้ตรงกัน

## 1. รูปแบบเกม

- เล่นได้ 3–7 คน
- ในแต่ละรอบมีผู้คุมกฎ (Rule Keeper) 1 คน ผู้คุมกฎไม่มีไพ่ในมือและไม่มีเทิร์นลงไพ่
- ผู้คุมกฎเปลี่ยนทุกครั้งเมื่อเริ่มรอบใหม่ โดยเลื่อนไปทางซ้าย/ตามเข็มนาฬิกา วนไปตามที่นั่งผู้เล่น
- ผู้เล่นคนแรกที่เล่นคือคนถัดจากผู้คุมกฎตามเข็มนาฬิกา
- หนึ่งเกมมีจำนวนรอบเท่ากับจำนวนผู้เล่น เช่น ผู้เล่น 4 คนเล่น 4 รอบ และผู้เล่น 5 คนเล่น 5 รอบ
- ผู้คุมกฎจะหมุนเวียนไปตามเข็มนาฬิกา ทำให้ผู้เล่นทุกคนได้เป็นผู้คุมกฎคนละ 1 รอบต่อเกม
- เมื่อเล่นครบจำนวนรอบแล้วจึงรวมคะแนนเพื่อตัดสินผล ผู้เล่นสามารถเลือกเลิกเล่นก่อนครบจำนวนรอบได้

## 2. สำรับไพ่

### ไพ่ตัวละคร

มีทั้งหมด 72 ใบ เป็นผลคูณของสัตว์ 4 ชนิด สี 3 สี และหมายเลข 1–6

- สัตว์: แมว, กระต่าย, กบ, สุนัขจิ้งจอก
- สี: ชมพู, ฟ้า, ทอง
- หมายเลข: 1, 2, 3, 4, 5, 6
- ID รูปแบบ `ANIMAL_COLOR_NUMBER` เช่น `CAT_PINK_01`

### ไพ่กฎเริ่มต้น

| ID | เงื่อนไข |
|---|---|
| R001 | ไพ่ต้องเป็นสีชมพู |
| R002 | ไพ่ต้องเป็นสีฟ้าหรือสีทอง |
| R003 | หมายเลขต้องเป็นเลขคี่ |
| R004 | หมายเลขต้องไม่ซ้ำกับไพ่ก่อนหน้า |
| R005 | ตัวละครต้องเป็นแมวหรือกระต่าย |

ชนิดเงื่อนไขในสำรับสามารถขยายได้ภายหลัง แต่ต้องไม่เปลี่ยนความหมายของกฎที่กำหนดไว้แล้ว

## 3. การเริ่มรอบ

- สุ่มไพ่ตัวละครเพื่อเลือกไพ่คำใบ้ที่ผ่านกฎลับ และวางเป็นไพ่เริ่มต้นบนโต๊ะ
- ไพ่คำใบ้ถูกนำออกจากกองจั่ว
- ผู้เล่นทุกคนยกเว้นผู้คุมกฎได้รับไพ่เริ่มต้นคนละ 7 ใบ
- ไพ่ที่เหลือเป็นกองจั่ว
- กองทิ้งเริ่มต้นว่าง
- ผู้เล่นถัดจากผู้คุมกฎตามเข็มนาฬิกาเป็นผู้เล่นคนแรก

## 4. การลงไพ่

ผู้เล่นที่ถึงเทิร์นเลือกได้ดังนี้

1. ลงไพ่ 1 ใบ
2. ลงไพ่หลายใบพร้อมกัน โดยเรียงลำดับไพ่ที่จะลง ทุกใบต้องผ่านกฎเมื่อประเมินต่อเนื่องจากไพ่ก่อนหน้า
3. แลกไพ่ทั้งมือ โดยยื่นไพ่ทั้งหมดให้ผู้คุมกฎตรวจ

### การลงไพ่ปกติ

- ตรวจไพ่ตามลำดับจากซ้ายไปขวา โดยอ้างอิงไพ่ล่าสุดบนโต๊ะหรือไพ่ก่อนหน้าในชุดที่กำลังตรวจ
- การลงหลายใบเป็นการตรวจแบบ atomic: หากมีแม้แต่ใบเดียวไม่ผ่าน จะไม่มีไพ่ใบใดถูกลง
- หากลงไม่ผ่าน ไพ่ที่พยายามลงทั้งหมดกลับเข้ามือ และจบเทิร์นทันที ส่งต่อให้ผู้เล่นคนถัดไป
- หากลงผ่าน นำไพ่ทั้งหมดที่เลือกออกจากมือและวางบนโต๊ะ
- หากผู้เล่นลงไพ่จนหมดมือ ให้เข้าสู่ช่วงทายกฎทันที

## 5. การแลกไพ่ทั้งมือ

ผู้เล่นใช้ทางเลือกนี้เมื่อมั่นใจว่าไม่มีไพ่ใบใดในมือที่ลงได้ โดยยื่นไพ่ทั้งหมดให้ผู้คุมกฎตรวจ

### ไม่พบไพ่ที่ลงได้

- ทิ้งไพ่ทั้งหมดจากมือของผู้เล่นลงกองทิ้ง
- จั่วไพ่คืนจำนวนเท่ากับจำนวนไพ่เดิมลบ 1 ใบ
- หากเดิมมีไพ่ 1 ใบ จะทิ้งใบนั้นและจั่ว 0 ใบ ทำให้มือว่างและเข้าสู่ช่วงทายกฎ

### พบไพ่ที่ลงได้อย่างน้อยหนึ่งใบ

- ผู้คุมกฎเลือกไพ่ที่ผ่านกฎ 1 ใบจากมือที่ยื่นมา แล้วลงใบนั้นบนโต๊ะ
- คืนไพ่ที่เหลือทั้งหมดให้ผู้เล่น
- ผู้เล่นจั่วเพิ่ม 1 ใบ
- เทิร์นจบและส่งต่อให้ผู้เล่นคนถัดไป

## 6. การจั่วและกองทิ้ง

- กองทิ้งจะไม่ถูกนำกลับมาสับเป็นกองจั่ว เพราะเป็นไพ่ที่ถูกตัดสินแล้วว่าไม่สามารถลงได้ในสถานการณ์ที่ตรวจ
- หากกองจั่วหมด ให้ถือว่าเกมจบ
- วิธีสรุปคะแนนเมื่อกองจั่วหมดก่อนมีผู้เล่นหมดมือยังต้องกำหนดเพิ่มเติม

## 7. การจบรอบและการจัดอันดับ

- เมื่อผู้เล่นคนแรกหมดมือ ให้หยุดการเล่นไพ่ทันทีและเริ่มช่วงทายกฎ
- ผู้เล่นคนนั้นได้อันดับ 1
- จัดอันดับผู้เล่นที่เหลือจากจำนวนไพ่ในมือ ณ ขณะที่ผู้เล่นคนแรกหมดมือ: ผู้ที่เหลือไพ่น้อยกว่าได้อันดับสูงกว่า
- จำนวนไพ่ในมือที่ใช้จัดอันดับเป็นค่าที่บันทึก ณ เวลานั้น ไม่เปลี่ยนตามขั้นตอนทายกฎ
- ผู้เล่นที่มีจำนวนไพ่เหลือเท่ากันได้อันดับเดียวกัน และได้รับคะแนนอันดับเท่ากัน
- ผู้คุมกฎของรอบนั้นไม่ได้รับคะแนนจากรอบดังกล่าว
- หลังจบการทายกฎ จึงสรุปคะแนนของรอบและเปลี่ยนผู้คุมกฎสำหรับรอบถัดไป

## 8. คะแนนอันดับพื้นฐาน

คะแนนตามอันดับที่กำหนดไว้มีดังนี้

| จำนวนผู้เล่น | อันดับ 1 → อันดับสุดท้าย |
|---|---|
| 3 คน | +1, 0, -1 |
| 4 คน | +2, +1, 0, -1 |
| 5 คน | +2, +1, 0, -1, -2 |
| 6 คน | +3, +2, +1, 0, -1, -2 |
| 7 คน | +3, +2, +1, 0, -1, -2, -3 |

สูตรคะแนนตามอันดับ: เริ่มจาก `floor((จำนวนผู้เล่น - 1) / 2)` แล้วลดลงทีละ 1 ตามอันดับ

ข้อกำหนดที่ยืนยันแล้ว: ผู้คุมกฎไม่ได้รับคะแนนในรอบที่ตนเองคุมกฎ เพราะในเกมที่มีจำนวนรอบเท่ากับจำนวนผู้เล่น ทุกคนจะได้เป็นผู้คุมกฎคนละหนึ่งรอบ

ยังต้องกำหนดให้ชัดว่าตารางคะแนนอันดับจะอ้างอิงจำนวนผู้เล่นทั้งหมดในเกมหรือจำนวนผู้เล่นที่ลงไพ่ในรอบนั้น เนื่องจากผู้คุมกฎไม่ได้รับคะแนนและไม่ได้ร่วมจัดอันดับ

## 9. การทายกฎลับ

- เมื่อผู้เล่นคนแรกหมดมือ ผู้คุมกฎนำไพ่กฎลับจริงมารวมกับไพ่กฎหลอกอีก 2 ใบ ให้ผู้เล่นที่หมดมือเป็นคนแรกทายจากตัวเลือก 3 ใบ
- หากทายถูก ผู้ทายได้รับโบนัสเพิ่ม 1 คะแนน และจบช่วงทายกฎ
- หากทายผิด ให้ส่งสิทธิ์ทายต่อไปยังผู้เล่นคนถัดไปตามเข็มนาฬิกาในลำดับผู้เล่น
- เมื่อส่งให้ผู้เล่นคนใหม่ ผู้คุมกฎนำไพ่กฎใบใหม่จากกองที่ยังไม่ถูกใช้มาเพิ่ม เพื่อให้มีตัวเลือก 3 ใบ
- ทำต่อไปจนกว่าจะมีผู้เล่นทายถูก
- โบนัส +1 เป็นคะแนนเพิ่มเติมจากคะแนนอันดับพื้นฐาน ผู้ที่ได้รับโบนัสอาจไม่ใช่ผู้เล่นที่หมดมือก่อน

## 10. เงื่อนไขจบเกม

- เกมจบเมื่อเล่นครบจำนวนรอบเท่ากับจำนวนผู้เล่น โดยผู้เล่นทุกคนได้ทำหน้าที่ผู้คุมกฎคนละหนึ่งรอบ
- เมื่อจบเกมให้นำคะแนนจากทุกรอบมารวมกันเพื่อจัดอันดับคะแนนรวม
- ผู้เล่นสามารถเลือกเลิกเล่นก่อนครบจำนวนรอบได้
- หากกองจั่วหมด เกมจบเช่นกัน แต่การคิดคะแนนในกรณีนี้ยังต้องกำหนดเพิ่มเติม

## 11. ประเด็นที่ยังรอการยืนยัน

ประเด็นเหล่านี้ห้ามผู้พัฒนาเดากติกาเอง ให้คงเป็น TODO จนกว่าจะได้รับคำตอบ

1. ตารางคะแนนอันดับจะอ้างอิงจำนวนผู้เล่นทั้งหมดในเกม หรือจำนวนผู้เล่นที่ลงไพ่ในรอบนั้น โดยผู้คุมกฎได้ 0 คะแนน
2. หากกองจั่วหมดก่อนมีผู้เล่นหมดมือ จะจัดอันดับและคิดคะแนนอย่างไร
3. ไพ่คำใบ้ถือเป็นไพ่ก่อนหน้าสำหรับกฎที่ขึ้นกับไพ่ก่อนหน้าหรือไม่
4. การแลกไพ่ทั้งมือ: หากพบไพ่ที่ลงได้ ผู้เล่นจั่ว 1 ใบตามกติกา แม้ไพ่ที่เลือกลงจะทำให้มือว่างชั่วขณะหรือไม่ (ตามกระบวนการปัจจุบัน ไพ่ที่เหลือจะถูกคืนก่อนจั่ว)

เมื่อมีการยืนยันประเด็นใด ให้แก้ไขเอกสารนี้ก่อนหรือพร้อมกับการแก้โค้ด เพื่อให้ไฟล์นี้เป็นแหล่งอ้างอิงหลักเสมอ
